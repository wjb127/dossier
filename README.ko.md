# dossier

**AI 코딩 에이전트가 검색하는 교차 프로젝트 색인.**

[English](README.md)

> 상태: 초기 설계 단계. 첫 릴리스는 Claude Code 플러그인 + 스킬(`/dossier`)로 나옵니다.

## 문제

AI 코딩 에이전트는 지금 서 있는 저장소 하나는 압니다. 나머지 이백 개는 모릅니다.

외주, 에이전시, 사이드 프로젝트처럼 여러 프로젝트를 동시에 굴리면 매일 묻는 질문은 코드가 아닙니다.
**어느 프로젝트인지**, **지난번에 무슨 일이 있었는지**입니다.

- "이 전화번호 고객 — 어느 폴더지?"
- "`shop.example.com` 은 우리가 배포한 사이트야, 아니면 참고하라고 보내준 사이트야?"
- "이건 어떻게 배포했더라? 어느 계정, 어느 브랜치?"
- "이 고객 API 토큰은 어디 있지? (값 말고 위치)"
- "지난번에 이 프로젝트 건드렸을 때 뭐가 터졌지?"

저장소별 기억 파일(`CLAUDE.md`, `AGENTS.md`)은 이 질문에 답하지 못합니다. 답이 저장소 **사이**에 있기 때문입니다.
대화 기억 도구는 내가 한 말을 기억할 뿐, 프로젝트들이 어떻게 놓여 있는지는 모릅니다.

## 아이디어

로컬에 색인 하나를 두고(프로젝트마다 *dossier* 한 장), 에이전트가 그 색인을 검색·갱신하고 바로 작업으로 이어가는 스킬을 줍니다.

| 원칙 | 뜻 |
|---|---|
| **사람이 기억하는 것으로 찾는다** | 폴더명만이 아니라 고객명, 별칭, 전화번호, 도메인, 태그로. 축마다 가중치가 있어 고객명 일치가 스쳐 지나간 언급보다 앞에 옵니다. |
| **도메인에는 역할이 있다** | 도메인은 *우리 것*(우리가 배포), *레퍼런스*(예시로 받은 사이트), *고객의 다른 사이트* 중 하나입니다. 섞으면 검색이 확신에 차서 틀립니다. |
| **병합은 사람이 이긴다** | 자동 추출은 감지할 수 있는 칸을 새로 고치지만, 사람이 분류한 값은 절대 덮어쓰지 않습니다. |
| **값이 아니라 위치** | 자격증명의 *위치*(보관함, 항목 id, 필드)만 적고 값은 적지 않습니다. 항목 제목이 프로젝트명과 달라 검색에 안 걸릴 때는 경고를 남깁니다. |
| **교훈이 쌓인다** | 에이전트가 어떤 프로젝트에서 함정을 밟으면 그 프로젝트의 `gotchas` 에 한 줄을 남깁니다. 다음 작업은 손대기 전에 그걸 먼저 읽습니다. |
| **찾고 나서 바로 한다** | 명령 한 줄로 프로젝트를 찾고, 함정과 배포법을 읽고, 수정·빌드·배포까지. 색인은 전화번호부가 아니라 발사대입니다. |
| **실제 상태를 잰다** | 도메인으로 물으면 DNS 를 조회하고 사이트를 열어 운영중 / 만료 / 미연결로 표시합니다. |

## 기존 방법과의 비교 (미리보기)

출처를 단 전체 비교는 `docs/ko/comparison.md` 에 올라갑니다. 지금은 가설입니다.

| 도구 계열 | 범위 | 고객·전화·도메인으로 검색 | 시크릿 위치 | 배포법 | 함정 학습 |
|---|---|---|---|---|---|
| 경로 이동 도구 (ghq, zoxide) | 폴더 | 없음 | 없음 | 없음 | 없음 |
| 소프트웨어 카탈로그 (Backstage) | 조직 서비스 | 소유 팀 기준 | 플러그인 | 일부 | 없음 |
| 저장소별 기억 (CLAUDE.md, AGENTS.md) | 저장소 1개 | 없음 | 글로 | 글로 | 일부 |
| 에이전트 메모리 (mem0, Letta, Zep 등) | 대화 | 의미 검색 | 없음 | 없음 | 간접 |
| 코드베이스 색인 (repomix, 코드 그래프 MCP) | 코드 구조 | 없음 | 없음 | 없음 | 없음 |
| **dossier** | **모든 프로젝트** | **가중치 검색** | **위치만** | **있음** | **있음** |

표의 칸은 전부 검증할 주장입니다. 다른 곳에 이미 있는 것으로 확인되면 "차이"가 아니라 "참고한 것"으로 옮깁니다.

## 개인정보

색인은 개인정보입니다. 고객명, 전화번호, 도메인, 자격증명 위치가 들어 있습니다.
dossier 는 색인이 내 컴퓨터 밖으로 나가지 않게 설계합니다.

- 색인 파일은 기본으로 git 이 무시합니다.
- 예시와 테스트는 가상 데이터만 씁니다.
- `tools/privacy-scan.py` 가 push 전에 파일과 **커밋 정보**를 내 컴퓨터에만 있는 금지어 목록과 대조합니다.
